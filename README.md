# student-registration-system
Student Registration System

About the Project
The Student Registration System is a beginner-friendly web application developed using PHP and MYSQL it allow user to enter student details through a registration form and store information in a database 

Technologies Used
PHP
MYSQL
HTML
CSS
XAMPP

Features
Student Registration System
Input fields for student details
MYSQL database integration
Save registred student records in the database
View Students records in table format
Search students by email or name
Edit student edit the existing details update
Delete Student records
